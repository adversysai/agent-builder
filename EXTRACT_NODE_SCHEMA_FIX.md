# 🔧 Extract Node Schema Fix

## ✅ **Problem Identified**

**Error**: `Invalid schema for response_format 'extraction': In context=(), 'additionalProperties' is required to be supplied and to be false.`

**Location**: `lib/workflow/executors/extract.ts` - OpenAI API calls

**Root Cause**: JSON schemas used with OpenAI's `response_format` must have `additionalProperties: false` explicitly set.

## 🔍 **Technical Details**

### **Issue Analysis:**
- **OpenAI API Requirement**: The `json_schema` response format requires `additionalProperties: false`
- **Missing Property**: Schemas generated by the system didn't include this required property
- **API Validation**: OpenAI validates the schema structure before processing
- **Error Impact**: Extract nodes fail to execute, breaking workflows

### **Error Context:**
```typescript
// Before fix - schema missing required properties
const schema = {
  type: "object",
  properties: { /* ... */ }
  // Missing: additionalProperties: false
};

// OpenAI API call fails with validation error
const response = await client.chat.completions.create({
  response_format: {
    type: 'json_schema',
    json_schema: {
      name: 'extraction',
      schema, // ❌ Invalid schema
      strict: true,
    },
  },
});
```

## 🛠️ **Fix Applied**

### **1. Schema Validation Enhancement:**
```typescript
// Parse JSON schema and ensure it has required properties for OpenAI
let schema = typeof data.jsonSchema === 'string'
  ? JSON.parse(data.jsonSchema)
  : data.jsonSchema;

// Ensure schema has required properties for OpenAI API
if (!schema.additionalProperties) {
  schema.additionalProperties = false;
}

// Ensure schema has required structure for OpenAI
if (!schema.type) {
  schema.type = 'object';
}
if (!schema.properties) {
  schema.properties = {};
}
```

### **2. Both API Paths Fixed:**
- ✅ **MCP Tools Path**: Responses API with schema validation
- ✅ **Regular Path**: Chat Completions with schema validation
- ✅ **Consistent Handling**: Both paths use the same schema validation

### **3. Robust Error Prevention:**
- ✅ **Required Properties**: `additionalProperties: false` always set
- ✅ **Type Validation**: `type: 'object'` ensured
- ✅ **Properties Validation**: `properties: {}` default if missing
- ✅ **Backward Compatibility**: Existing schemas still work
